Micro-frontend: <cv-mfe>

A separate Angular app with its own repository and deployment, at {{ remoteUrl }}. This app does not contain its code: it is loaded in the browser, when this page opens.

  1. At startup, initFederation() reads federation.manifest.json, which maps the name cv-mfe to the remote's remoteEntry.json.
  2. Here, Wrapper (@cv/shared-ui-federation) calls loadRemoteModule('cv-mfe', './web-components').
  3. That module registers the custom element <cv-mfe> (Angular Elements), and the wrapper adds it to the page.
  4. Angular and RxJS are shared with this app as singletons (Native Federation), so they are downloaded once.

Component library: <lib-mac-window>

Anything placed here is projected into the window.

The opposite approach, for comparison: MacWindow lives in this repository (packages/mac-window) and is published to npm as @axel-pauwels/mac-window.

  • Bundled into this app at build time, not loaded at runtime.
  • Also ships as the web component <mac-window> (@axel-pauwels/mac-window/element), for any framework.
