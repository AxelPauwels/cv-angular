Public API: barrels and internal/

  • Every library has one entry point, src/index.ts, imported as @cv/<project>. Deep imports into a library are not allowed.
  • What the barrel does not export lives in src/lib/internal/. A lint rule stops a barrel from exporting anything from there.
  • Feature libraries default-export their page, so a route lazy-loads it with loadComponent: () => import('@cv/…').

Layers inside a domain

  1. feature: a routed page. Injects a store and renders its signals.
  2. data-access: a root signal store (NgRx Signals) that loads once and is shared app-wide. Internally a service runs a typed GraphQL query and a mapper turns the generated API types into hand-written frontend types.
  3. api: the GraphQL schema and resolvers (@cv/api), answered in the browser for now.
  4. ui and util: presentational components and plain functions or types, shared without knowing about data.
